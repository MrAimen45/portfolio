# Portfolio Visual Elevation Plan

**Context:** The current portfolio is functional but feels like a generic template. We are elevating it to a high-end, premium, and distinctive "Cyber-Industrial" design.

## Typography
- **Headlines:** Use 'Syne' (Variable font) — bold, wide, editorial.
- **Body:** Use 'Plus Jakarta Sans' — highly legible, modern, and friendly.
- **Approach:** Fluid font scaling with `clamp()` for responsive text.

## Color & Hierarchy
- **Palette:** Deep Industrial Slate (Backgrounds), Cyber-Cyan (Data/Primary), Safety Amber (Warnings/Attention), Operational Emerald (Safety).
- **Hierarchy:** High contrast between headings and body; generous spacing to emphasize key content.

## Implementation Steps
1. [ ] Update `index.html` to load new Google Fonts (Syne, Plus Jakarta Sans).
2. [ ] Redefine CSS variables in `style.css` for typography and spacing.
3. [ ] Apply typography to global components (headings, body).
4. [ ] Refactor hero section layout and spacing to create a stronger visual anchor.
5. [ ] Verify accessibility (WCAG AAA) across all text elements.
